The schema loader follows Cap'n Proto C++ 1.4.0 on malformed struct and enum nodes. A union discriminant is checked with the 32-bit product `(discriminantOffset + 1) * 16`, so an offset that wraps still loads. A one-member union, a repeated field name, a codeOrder outside the field list, a slot offset past the struct, and a repeated enumerant name are omitted. Other nodes from the same request remain available. A field offset that wraps in that same 32-bit product still loads, and decoding it still reports `bad value`.
