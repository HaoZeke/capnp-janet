capnp-janet
===========

Native Cap'n Proto runtime for `Janet <https://janet-lang.org>`_, plus a
C library embedders can link without the Janet VM.
#+end_export

Sibling runtimes: [[https://c-capnproto.rgoswami.me][c-capnproto]] and
[[https://capnp-fortran.rgoswami.me][capnp-fortran]]. Status: =0.2.5=.
AddressBook encode matches official =capnp encode= when fields are set
in schema order.

* Install (shortest path)

#+begin_src console
$ git clone https://github.com/HaoZeke/capnp-janet.git
$ cd capnp-janet
$ pixi install && pixi run configure && pixi run build && pixi run test
#+end_src

* First message (Janet)

Allocate the root and its nested values in one growable arena:

#+begin_src janet
(import capnp)

(def builder (capnp/new-builder))
(def body (capnp/init-root builder 1 1))
(capnp/set-u32 body 0 42)
(capnp/set-text body 0 "hello")
(def buf (capnp/finish-builder builder))
(def root (capnp/root (capnp/message-from-buffer buf)))
(print (capnp/get-u32 root 0))        # 42
(print (capnp/get-text root 0))       # hello
#+end_src

Lists come out of a decoded message, such as the shipped =capnp encode=
golden. A list pointer carries Janet's =length=, index and iteration
protocols, so it answers to the same forms as an array:

#+begin_src janet
(def msg (capnp/message-from-buffer
           (slurp "test/fixtures/addressbook_alice_bob.bin")))
(def people (capnp/getp (:root msg) 0))

(length people)                       # 2
(:text (in people 0) 0)               # "Alice"
(map |(string (:text $ 0)) people)    # @["Alice" "Bob"]
(each p people (print (:u32 p 0)))
#+end_src

=(:verb receiver ...)= reaches the same accessors as the =capnp/=
functions: =:kind=, =:ptr=, every signed and unsigned scalar width,
=:f32=, =:f64=, =:bool=, =:text=, and typed =:*-at= list readers. A
message answers to =:root=.

C embed (no Janet VM):

#+begin_src c
#include <capnp-janet/capnp_message.h>

capnp_message_t msg;
capnp_message_view_flat(&msg, bytes, len);
capnp_ptr_t root;
capnp_root(&msg, &root);
const char *s; size_t n;
capnp_get_text(&root, 0, &s, &n);
#+end_src
